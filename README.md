# 🍓 너잘달 (너나 잘해라 달력) — 설치 가이드

로그인 없이 **가족 비밀번호만 입력하면** 가족 모두가 일정을 추가·수정·삭제할 수 있는 달력 앱이에요.
아이폰·안드로이드 홈 화면에 앱처럼 설치되고, 아침 7시에 알림이 와요.

> 💰 **비용: 0원.** GitHub(앱 주소 + 아침 알림 발송)와 Firebase 무료 요금제(가족 데이터 저장)만 써요.
> ⏱️ 처음 한 번 설정하는 데 30~40분 정도 걸려요. 가족들은 그 뒤에 링크만 받아서 설치하면 돼요.

---

## 미리 체험해보기 (설정 없이)

`config.js`를 비워둔 채로 `index.html`을 열면 **데모 모드**로 동작해요. (그 기기에만 저장되고 가족과 공유는 안 돼요.)

---

## 1단계. GitHub에 올려서 앱 주소 만들기

1. [github.com](https://github.com)에 가입하고 로그인
2. 오른쪽 위 **+** → **New repository**
   - 이름: `family-calendar` (원하는 대로)
   - **Public** 선택 → **Create repository**
3. **uploading an existing file** 클릭 → 압축을 푼 폴더 안의 **모든 파일과 폴더**를 끌어다 놓기 → **Commit changes**
   - ⚠️ `.github` 폴더가 숨김 폴더라 안 보일 수 있어요. 맥은 Finder에서 `Cmd + Shift + .` 을 누르면 보여요.
4. 저장소의 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 나오는 주소가 우리 앱 주소예요.
   예) `https://내아이디.github.io/family-calendar/`

## 2단계. Firebase로 가족 공유 저장소 만들기

1. [console.firebase.google.com](https://console.firebase.google.com) → 구글 계정으로 로그인 → **프로젝트 만들기** (애널리틱스는 꺼도 돼요)
2. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: **asia-northeast3 (서울)**
   - **프로덕션 모드**로 시작
3. Firestore 화면 위쪽 **규칙** 탭 → 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여넣기 → **게시**
4. 프로젝트 개요 옆 ⚙️ → **프로젝트 설정** → 아래쪽 **내 앱**에서 `</>` (웹) 아이콘 → 앱 이름 입력 → **앱 등록**
5. 화면에 나오는 `firebaseConfig = { ... }` 안의 값 6개를 `config.js`의 `firebase: { ... }` 에 그대로 옮겨 적기

## 3단계. 가족 비밀번호 (이미 설정됨 ✅)

비밀번호 **hanna1224** 가 `config.js` 에 이미 들어가 있어요. 이 단계는 건너뛰세요.
5단계에서 쓸 `FAMILY_KEY` 값은 아래와 같아요.

```
1646e69245efef95f44d1565414f91211253b941b1dd8bc06f8c843049820dd3
```

> 가족들은 **앱을 처음 설치할 때 한 번만** 비밀번호를 입력해요. 그 뒤로는 바로 열려요.

## 4단계. 아침 7시 알림 키 만들기

1. 압축 푼 폴더의 `tools/vapid.html`을 크롬이나 사파리로 열기 → **키 만들기**
2. ① 공개키 → `config.js`의 `vapidPublicKey`에 붙여넣고 Commit (5단계에도 사용)
3. ② 비밀키 → 5단계에서만 사용 (어디에도 공유하지 마세요)

## 5단계. GitHub에 비밀값 넣기 (아침 알림 발송용)

1. Firebase **프로젝트 설정 → 서비스 계정** 탭 → **새 비공개 키 생성** → JSON 파일이 다운로드돼요
2. GitHub 저장소 **Settings → Secrets and variables → Actions**
3. **Secrets** 탭에서 **New repository secret** 으로 4개 추가:

| 이름 | 넣을 값 |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 다운로드한 JSON 파일을 메모장으로 열어서 **전체 내용** |
| `FAMILY_KEY` | 3단계의 값 |
| `VAPID_PUBLIC_KEY` | 4단계의 ① 공개키 |
| `VAPID_PRIVATE_KEY` | 4단계의 ② 비밀키 |

4. 옆의 **Variables** 탭 → **New repository variable**
   - 이름 `APP_URL`, 값: 1단계에서 받은 앱 주소

## 6단계. 가족 폰에 설치하기 📱

가족 단톡방에 앱 주소를 공유하고 각자:

**아이폰** (iOS 16.4 이상)
1. 링크를 **Safari**로 열기 (카톡이면 오른쪽 아래 `⋯` → Safari로 열기)
2. 아래쪽 **공유 버튼** → **홈 화면에 추가**
3. 홈 화면의 **너잘달** 아이콘으로 열기 → 비밀번호 입력 → "누구세요?"에서 본인 선택
4. 오른쪽 위 내 얼굴 → **아침 7시 알림 받기** → 허용

**안드로이드**: 크롬으로 열기 → 메뉴 `⋮` → **앱 설치(홈 화면에 추가)** → 이후 동일

> 알림은 반드시 **홈 화면 아이콘으로 연 앱 안에서** 켜야 해요. (아이폰 정책)

## 7단계. 알림 테스트

GitHub 저장소 **Actions** 탭 → 왼쪽 **아침 7시 가족 알림** → **Run workflow** → 칸에 `yes` 입력 → Run
→ 알림을 켜둔 모든 폰에 "🔔 테스트 알림이에요"가 오면 성공! 🎉

## 가족 생일 (자동 입력)

`config.js`의 `birthdays`에 적힌 생일은 앱을 처음 열 때 **한 번만** 달력에 자동으로 들어가요.

| 이름 | 생일 | 비고 |
|---|---|---|
| 아빠 | 1971.06.17 | **음력** → 매년 양력으로 자동 변환 (예: 2026년 7월 30일) |
| 엄마 | 1971.04.19 | **음력** → 2026년 6월 4일 |
| 한나 | 1998.12.24 | 양력 |
| 한영 | 2001.02.06 | 양력 |
| 보현 | 2003.08.11 | 양력 |
| 외할아버지 | 음력 4.15 | **음력** → 2026년 5월 31일 |

새 일정을 추가할 때도 생일·결혼기념일·외할아버지 생신은 **"음력으로 입력"**을 켤 수 있어요.

## 얼굴 스티커

- `icons/faces/` 폴더에 스티커 이미지를 넣고 `config.js`의 `faces`에 연결하면 모든 가족 폰에 기본으로 보여요.
- 앱 안에서 **설정 → 얼굴 스티커 바꾸기**를 누르고 사진을 고르면, 흰 테두리가 있는 동그란 스티커로 자동 변환돼서 가족 모두에게 공유돼요.

## 앱 기능 정리

| 행사 | 아이콘 | 아침 7시 알림 | 매년 반복 |
|---|---|---|---|
| 🎂 생일 | 가족은 얼굴 스티커 + 케이크 배지 | 자동 | 자동 (음력 가능) |
| ✈️ 여행 | 비행기 | 자동 (출발일) | — |
| 💍 엄마 아빠 결혼기념일 | 반지 | 자동 (몇 주년인지 표시) | 자동 |
| 🏠 Way Back Home | 하트 집 + 한나·한영·보현 체크 | 선택 | — |
| 👴 외할아버지 생신 | 할아버지 | 자동 | 자동 (음력) |
| ⭐ 직접 입력 | 추가한 사람 얼굴 (가족 얼굴·이모지로 변경 가능) | 선택 | 선택 |

- 모든 일정은 **시작일 ~ 종료일** 설정 가능 (여러 날 일정은 달력에 막대로 이어져 보여요)
- 누가 추가/수정했는지 얼굴로 표시
- 다른 가족이 일정을 바꾸면 **실시간으로** 내 화면에도 반영
- 날짜가 바뀌면 오늘 표시·D-day·"오늘의 가족 행사" 배너가 자동 갱신
- 달력은 좌우로 밀어서 달 이동, 날짜를 두 번 누르면 바로 일정 추가
- 가족 얼굴 사진은 설정에서 등록 (가족 모두에게 공유)
- 인터넷이 없을 때도 마지막으로 본 달력은 열려요

## 일정 상세 · 좋아요 · 댓글

일정을 누르면 상세 화면이 열려요. ♡ 좋아요를 누르면 누가 눌렀는지 얼굴이 보이고, 아래에 댓글을 달 수 있어요 (내 댓글만 삭제 가능). 다른 가족이 단 댓글·좋아요도 실시간으로 보여요.

## 인터넷이 없을 때

- 한 번이라도 인터넷에 연결된 상태로 앱을 열었다면, 와이파이·데이터가 없어도 앱이 열리고 저장된 달력이 보여요.
- 오프라인에서 일정 추가·수정·댓글·좋아요를 해도 폰에 먼저 저장되고, **인터넷이 다시 연결되면 자동으로 가족들에게 전달**돼요.
- 아침 7시 알림은 인터넷이 연결되어 있어야 받을 수 있어요 (연결되면 늦게라도 도착해요).

## 자주 묻는 질문

**Q. 알림이 정확히 7시에 안 와요.**
GitHub의 예약 실행은 붐비는 시간에 몇 분 늦을 수 있어요. 6시 50분에 시작해서 7시까지 기다렸다가 보내도록 해뒀지만, 가끔 5~15분 늦을 수 있어요.

**Q. 가족 이름을 바꾸거나 추가하고 싶어요.**
`config.js`의 `members`(전체 가족)와 `wayBackHome`(체크 대상)을 고치면 돼요.

**Q. 알림이 안 와요.**
① 아이폰은 홈 화면 아이콘으로 열었는지 ② 설정에서 "✅ 이 기기에서 알림을 받고 있어요"인지 ③ GitHub Actions 탭에서 실행 기록에 빨간 ❌가 없는지 확인해보세요.

**Q. 60일 동안 저장소에 변화가 없으면?**
GitHub는 오래 활동이 없는 저장소의 예약 실행을 멈출 수 있어요. 이메일로 안내가 오면 Actions 탭에서 **Enable workflow**를 누르면 다시 동작해요.

## 파일 구성

```
index.html              앱 화면 전체
config.js               ← 여기만 수정하면 돼요
sw.js                   오프라인 & 알림 수신
manifest.webmanifest    홈 화면 설치 정보
icons/                  앱 아이콘 (faces/ = 가족 얼굴 스티커)
firestore.rules         Firebase 보안 규칙
tools/vapid.html        알림 키 만들기 도구
notify/                 아침 알림 발송 스크립트
.github/workflows/      매일 아침 자동 실행 설정
```
